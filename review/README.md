# Вопросы и обратная связь

Журнал пока пуст. Ниже — порядок передачи вопросов, не фактические отзывы.

Если хотите, чтобы вопрос попал автору, можно создать [GitHub Issue](https://github.com/fomotya-cyber/rbtg-x-tbank-open-knowledge-base/issues/new) либо передать обезличенный текст автору для публикации после согласия. GitHub Issues публичны и показывают учётную запись создателя; если анонимность важна, используйте второй способ. Не включайте имена, контакты, данные сотрудников, ссылки на закрытые материалы и полный текст личного диалога.

Шаблон записи:
- Вопрос или замечание (обезличенный текст)
- Связанный COMP / US / HYP (если известен)
- Что неясно или отсутствует в аргументации
- Статус: открыт / уточнён / проверен / закрыт
- Ответ или ссылка на обновлённую публичную документацию

Это журнал обратной связи, не источник требований и не автоматическая фиксация переписки.
